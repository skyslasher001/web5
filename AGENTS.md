UNIVERSE is a local-first Windows desktop "digital brain": Electron + React UI, Python/FastAPI services, SQLite + LanceDB, local models via Ollama.

## How to work

- One phase at a time (SPEC §25). A phase ends with runnable code, tests, setup steps, a demo script, known limitations, and what's next (as a `docs/PHASE-N.md`).
- Simple over clever. No abstractions beyond the plugin interfaces.
- Verify current versions, models and licenses online before adding or upgrading anything. Don't rely on memory.
- Record decisions as ADRs in `docs/adr/` (template in `docs/adr/README.md`). Flag in 1–2 lines anything that materially changes cost, privacy, security or architecture.
- When something fails, show the real error and fix it. Never paper over failures with mocks. Test doubles are only for external services we can't run in CI (`tests/support/fake_ollama.py`).
- Keep this file and `CLAUDE.md` current when commands, layout or rules change. This file is the single source of truth for every AI assistant: the tool-specific files (`CLAUDE.md`, `.github/copilot-instructions.md`, `.gemini/settings.json`, `.aider.conf.yml`) only point here, and [`docs/HANDOFF.md`](docs/HANDOFF.md) explains how any assistant picks up the work (start prompt, how a phase is delivered, environment notes).

## Hard rules

- **Protected core — never modify** the paths in [`protected-core.txt`](protected-core.txt): the supervisor, `services/core/src/universe_core/protected/` (audit writer; later the permission engine, consent, budget caps, kill switch), Sentinel, `apps/desktop/src/main/protected/`, the safe-mode page, `agents/forge.yaml`, `agents/sentinel.yaml` (and their prompts), Forge's own guards and checks (`forge.py`, `forge_tools.py`, `forge_verify.py`), `tests/protected/`, CI and pre-commit config, and the manifest itself. For these, write a proposal for the owner to apply: a patch plus an explanation in `docs/proposals/`, tested in a scratch worktree.
- **Never disable, skip or weaken a test**, loosen an assertion, or lower a threshold to make something pass. Every bug fix ships a regression test.
- **Never delete or rewrite vault data.** Tests use temporary vaults (`tmp_path`), never a real vault path.
- **Licenses:** only MIT / Apache-2.0 / BSD / ISC / Zlib / OFL / MPL-2.0 (plus CC-BY-4.0 weights with attribution). Flag GPL, AGPL or non-commercial items with an alternative before adopting them. See [ADR-0008](docs/adr/0008-license-policy.md).
- **No secrets** in code, config, logs or commits. Use the OS credential store (`keyring`). Register any token with `universe_common.log.register_secret` so logs redact it.
- **Outbound network only through the egress gate** (`universe_common.egress`). `tests/protected/test_invariants.py` fails on direct HTTP clients. The Electron e2e test fails on any non-loopback request.
- **The supervisor imports only the standard library.** It runs with `python -I -S`.
- **Consent stays off by default:** mic, screen and camera. Nothing captured is stored unless the owner says so.
- **Generated files** (`packages/design-tokens/generated/`, `packages/shared-types/src/{api,events}.ts`, `openapi.json`) are never edited by hand: run `pnpm tokens` / `pnpm gen:types`.

## Layout

- `services/core` — FastAPI app (`app.py`), REST (`api.py`, `vault_api.py`, `vault_admin_api.py`; every handler `async def`, a test enforces it), WebSocket hub (`ws.py`), event bus + catalog (`events.py`), chat (`chat.py`), vault runtime (`vault_runtime.py`: the vault DB thread, worker processes, governor), backups (`backups.py`), migrations (`migrations/<db>/NNNN_name.{up,down}.sql`, never edit an applied one).
- `services/vault` — the vault (ADR-0010): file types and storage layout, ingest, job queue (`jobs.py`), governor, pipeline stages and handlers, worker process (`worker.py`), extraction, OCR and thumbnails (`media.py`), LanceDB vectors, query parser and hybrid search, trash/purge, folder watcher, restic backups, links and `[[wikilinks]]` (`links.py`, also neural-pathway firings: `record_activity` into `link_activity`, emitted as `link.fired`), the Semantic layout (`semantic.py`, a `layout` job cached in `layout_cache`). Vault DB work in Core goes through `ctx.vdb.run`.
- `services/agents` — agent YAML schema (`registry.py`), streaming tool-calling provider, model router (`resolve(tier, needs_tools=…)`), the agent loop (`runtime.py`: steps, guardrails, taint, the `Policy` protocol) and the tool interface (`tools.py`). No Core or database imports.
- Agent engine in Core — `agent_engine.py` (tasks, steps, approvals, delegation, Critic review, usage ledger), `agent_tools.py` (built-in tools), `memory.py`, `mcp_client.py` (minimal stdio MCP client + manager), `agents_api.py` (REST, including the roster), `agent_roster.py` (the Agents tab: built-in agents from `agents/`, the owner's own agents in `<data dir>/agents/`, agents turned off, synopsis edits, stats; ADR-0013). Forge (ADR-0014) is `forge.py` (issues and triage, worktrees on `forge/<id>` under `<data dir>/forge/`, proposals, protected-path guards, the daily cap), `forge_verify.py` (repro fails on base and passes on head, then ruff, pyright, pytest, eslint/Vitest; scrubbed environment), `forge_tools.py` (Forge's tools: no apply tool exists) and `forge_api.py` (REST; Core accepts "applied" only when git agrees). Sentinel's deterministic diff review is `protected/sentinel.py`. Universe REST is `universe_api.py`: columnar scene data, links, the Semantic layout, note content with versions, similar items. The policy engine, permission rules, budget caps and kill switch live in `protected/` and load through `context.load_safety`; absent, `NO_SAFETY` applies and agents chat without tools.
- `services/voice` — Voice (Phase 7, ADR-0016): the voice process `python -m universe_voice` (Starlette WS on loopback, HMAC single-use tickets from Core): `audio.py`, `features.py` (Whisper log-mel), `stt.py` (Whisper ONNX), `vad.py` (Silero + energy VAD, endpointer), `tts.py` + `g2p.py` (Kokoro, misaki lexicons), `wake.py` (transcript wake phrase), `session.py` (modes, barge-in), `models.py` (catalog pinned by SHA-256, `place`), `longform.py` (whole recordings; ffmpeg only as a separate executable). No Core imports. Core: `voice_runtime.py` (VoiceManager: spawn/health/backoff/kill switch; ModelInstaller through the egress gate), `voice_api.py` (REST + the `/ws/voice` relay). The vault's `transcribe` stage is `transcription.py`. Renderer: `lib/voiceClient.ts`, `lib/voice.ts`, `lib/voiceCommands.ts`, `hud/VoiceOrb.tsx`, `hud/VoicePanel.tsx`, `public/voice-capture.worklet.js`. Consent is protected Electron main (`protected/consent.ts`, applied 2026-10-21) and recorded by Core's `protected/consent_api.py`.
- `services/research` — Research (Phase 6, ADR-0015): web search providers (gated-httpx DuckDuckGo-Lite default, SearXNG loopback), page fetch + trafilatura extraction, a TTL cache, and spotlighting. Pure (no Core/DB-of-Core imports; clients come from the egress gate). Core wires it into the `researcher` agent's tools (`research_tools.py`: `web.search` / `web.fetch` / `vault.save`), the REST (`research_api.py`: `POST /research`, `/watchlists` CRUD, `/research/requests`), the scheduled watchlist runner (`watchlists.py`), and migration 0008.
- `agents/` — one YAML per agent (core, navigator, librarian, scribe, critic, researcher; plus the protected forge/sentinel), each with a `purpose` and a `synopsis`, and prompts in `agents/prompts/`. The app never edits these: the owner's agents live in `<data dir>/agents/`, and Core and Critic can't be turned off.
- `services/models` — hardware detection, loadouts (`loadouts.yaml`), Ollama client.
- `services/common` — config helpers, UUIDv7, logging, error capture, egress gate, SQLite helpers (incl. `snapshot`), parent watch (`orphan.py`), `ApiModel` (base class for API models: fields the server always sends become required in the generated types).
- `services/supervisor` — watchdog (stdlib only); entry `run_supervisor.py`. `releases.py` (Phase 5 patch, applied) applies approved Forge changes (re-checking everything against its own manifest copy), watches them for 30 minutes, rolls back with revert commits.
- `apps/desktop` — Electron main (`src/main`: window, command bar window + global shortcut, tray, clipboard capture, vault path checks; `protected/forge.ts`: the native approval dialog, apply/rollback through the supervisor, re-syncing Core's record when Core comes back), preload, safe-mode page. `apps/ui` — React HUD (`hud/`: incl. `AgentsPanel` tasks/traces/memory, `AgentRoster` (Agents panel → Roster), `SafetyPanel` kill switch/budget/rules/MCP/audit, `ApprovalsTray`, `KillSwitch`, `ForgePanel` (reports, issues, proposal cards), `SystemPanel` with `VitalsOverview` and Releases, `PerfHud` (optional perf overlay, off by default, fed by `lib/perf.ts`)), 2D grid/list (`views2d/`), command bar app (`command/`, served at `#command-bar`), and the universe (`universe/`: `Scene.tsx` picks the WebGL scene or `LiteScene.tsx` (sigma, 2D) by `quality.ts`; `scene/` holds the layouts and their Web Worker, scene data, shaders, camera rig, smooth zoom (`zoom.ts`), galaxies, filaments, probes (they fly the link paths), signal pulses (`Pulses.tsx`), labels, bloom). Viewers and galaxy dashboards are in `hud/viewers/`; the navigator (minimap, breadcrumb, layouts, time slider) is `hud/NavigatorCard.tsx`. `window.__universeDebug` exposes camera, items, layout and results to the e2e tests and the benchmark. Item queries refresh through `lib/queryClient.ts`; agent-engine queries refresh from events (`refreshForEvent`).
- `tests/unit`, `tests/integration`, `tests/protected`, `tests/e2e`, `tests/support` (fake Ollama with concept embeddings and a scripted tool-calling model, an MCP demo server, fake Core, tiny GGUF model writer, test file writers, the 500-file seed generator (the 50k universe seed is `scripts/seed_universe.py`), an in-memory keyring).
- `docs/proposals/` — protected-core changes proposed to the owner (patch + explanation + status).
- `docs/handoff/` — `PROJECT-BRIEF.md` (everything so far in one document) and `DECISIONS.md` (every owner message and decision, verbatim). Keep both current when a phase is delivered or approved. `llms.txt` at the root indexes the docs for AI tools; `scripts/export_handoff.py` builds the download package.
